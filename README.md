# 🛒 E-Commerce Sales & Profitability Analysis

Power BI dashboard for analyzing e-commerce sales, profitability, customers, products, categories, segments, and regional performance.

## 📌 Project Overview

This project analyzes e-commerce sales data using **Microsoft Power BI** to understand sales performance, profitability, customer segments, product categories, and regional trends.

The dashboard provides interactive visualizations, KPIs, filters, and analytical insights to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales performance
- Analyze total profit and profitability
- Compare sales across product categories
- Analyze sales by customer segment
- Identify top-performing products
- Analyze regional and state-wise sales
- Understand monthly sales and profit trends
- Identify products and categories with higher profitability
- Find important patterns and trends in e-commerce data

## 📊 Key KPIs

- **Total Sales**
- **Total Profit**
- **Average Profit**
- **Total Orders**
- **Total Quantity**
- **Profit Margin**

## 📈 Dashboard Analysis

The dashboard includes:

- Sales performance analysis
- Profitability analysis
- Category-wise sales
- Sub-category-wise sales
- Segment-wise sales
- Region-wise performance
- State-wise sales analysis
- Monthly sales and profit trends
- Top 10 products analysis
- Interactive slicers and filters

## 📂 Dataset

The project uses an e-commerce sales dataset containing information about:

- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Sales
- Quantity
- Discount
- Profit
- Region
- State
- Segment

## 🔄 Data Preparation

The following data preparation steps were performed:

1. Imported the dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Handled missing and inconsistent values.
4. Checked data types and column formats.
5. Created calculated columns and measures using DAX.
6. Built relationships between required tables.
7. Created KPIs and interactive dashboard visuals.
